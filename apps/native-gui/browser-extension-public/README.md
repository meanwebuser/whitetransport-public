# WhiteTransport Telemost Link

Расширение копирует ссылку на открытую встречу Телемоста по нажатию кнопки.
Разрешение `activeTab` даёт доступ к адресу текущей вкладки при открытии
расширения. В буфер обмена попадёт адрес вида `https://telemost.yandex.ru/j/…`.
Параметры ссылки и фрагмент после `#` удаляются.

## Установка

1. Скачайте `WhiteTransport-Telemost-Chrome-0.1.0.zip` и распакуйте архив.
2. Откройте `chrome://extensions` в Chrome или `edge://extensions` в Microsoft Edge.
3. Включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите папку `WhiteTransport-Telemost-Link`.

## Использование

Откройте встречу на `telemost.yandex.ru`. В меню расширений браузера выберите
**WhiteTransport Telemost Link**, затем нажмите **Скопировать ссылку**. После
сообщения «Ссылка скопирована» её можно вставить из буфера обмена.
